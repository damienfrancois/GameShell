Mission goal
============

Slurm will kill jobs that over use resources or fail to end withing the time limit. 

The goal of the mission is to submit a job that uses more memory than requested and consequently get it killed.

To that end, create a submission script that will request for instance 10M of RAM and will use more than that. Submit then the script and wait until the job has finished. The mission will be successful if the STATE of the latest of your jobs is OUT_OF_MEMORY.

Useful information
==================

In Bash, you can trigger an out of memory by running

    tail /dev/zero

Remarks
-------

1M per core is the minimum that can be requested.
