Mission goal
============

The scripts and the data files you will work on are in the `parcomp`
directory of your home directory. Enter it and look at the contents of the
`d.txt` file. Then, run the `lower.sh` script with that file as argument.
How much time does it approximately take?

When done, run `gsh check`.

Useful commands
===============

cd DIRECTORY
  changes current working directory to DIRECTORY
ls
  lists the contents of the current directory
cat FILE
  shows contents FILE

Remarks
-------

To run the script, you need to specify the path explicitly with `./lower.sh FILE`.
If you forgot to given an argument, the script will wait indefinitely. In that case,
hit CTRL-C to regain control of the terminal.

By not specifying a second argument, the output will be written to the terminal.

Some missions rely on tools that are not always installed on a laptop:
- GNU parallel (from mission 12 on): `brew install parallel` on macOS,
  `sudo apt install parallel` on Debian / Ubuntu,
- GNU split (mission 10, macOS only): `brew install coreutils`.
Installing them now avoids interrupting the game later.
